Built for speed, not another chat tab.

One hotkey. Your models. Answers without leaving what you’re doing.

  • Menu bar native

    No Dock clutter. Lives quietly until ⌥Space — then a floating panel, Spotlight-style.

  • Your providers

    OpenCode Go, DeepSeek, or any OpenAI-compatible API. Switch active model from the panel.

  • Keys stay local

    API keys stored in Application Support on your Mac. Nothing phoned home by QuickAsk.

  • Optional web search

    When you need live facts, QuickAsk can search and stream the answer into the same thread.

Install in a minute.

Unsigned build — first open may need a right-click → Open.

  1. 1

    Download

    Get the DMG and open it.

  2. 2

    Install

    Drag QuickAsk onto the Applications shortcut in the window.

  3. 3

    Add a key

    Settings → paste OpenCode Go or DeepSeek → Use as active.

  4. 4

    Ask

    Press ⌥Space, type a question, hit Return.
